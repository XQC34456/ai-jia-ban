## 三、IA 调整建议（关键决策）

**问题**：`health`（财富健康）与 `allocation`（资产配置）重叠。

**建议**：
- **`health` = 7 维财富健康全景**（雷达图 + 现金流/流动性/负债/保障/配置/养老/目标 各维下钻，薄弱维高亮）。
- **`allocation` = 资产配置诊断**（把现在 health.js 里的「配置体检 7 段」搬过来，配环形图 + 当前vs目标 + 调仓模拟）。
- **现金流 / 负债 / 保障 不单独建 nav 页**（避免导航膨胀 + 图表墙），作为 `health` 的三个维度区块下钻，各自带图表 + 「问顾问」+ 「加入计划」。

> 理由：你已强调「不要让每个页面都变成图表墙」「每个页面有重点」。9 个 nav 项已够，再加 3 个会稀释焦点。现金流/负债/保障本质是「健康维度」，归入 health 最自然。
